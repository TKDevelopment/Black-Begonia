# Provider Configuration Checklist

Complete and attach provider screenshots outside source control before activation:

- [ ] Google Ads and other advertising product links disabled
- [ ] Google Signals disabled
- [ ] Ads personalization, advertising storage/user data, and remarketing disabled
- [ ] User-provided data collection disabled
- [ ] Audience activation disabled
- [ ] URL passthrough and cross-site advertising measurement disabled
- [ ] Unnecessary account/property data sharing disabled
- [ ] Granular device/location reporting reviewed and minimized
- [ ] Enhanced Measurement page changes, forms, scroll, outbound clicks, and downloads disabled
- [ ] `generate_lead` is the only key event
- [ ] Only measurement-dictionary dimensions registered
- [ ] 14-month retention; reset-on-new-activity off

This source checklist does not prove the external settings are configured.
