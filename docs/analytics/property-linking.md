# Search Console and GA4 Linking

Status: **Waiting for authorized production properties.**

Link the verified Search Console Domain property to the production GA4 web stream using named,
least-privilege business accounts, then publish the native Search Console report collection. Record
the property/stream display names, owner, and verification date—never credentials.

Search Console and GA4 totals are not expected to match because consent, attribution, canonical URL
processing, time zones, privacy thresholds, query anonymization, and reporting delays differ.
