# Prohibited Analytics Data Incident Response

1. Contain: blank the production Measurement ID and verify no new Google requests.
2. Preserve only minimal diagnostic evidence; do not copy prohibited values into tickets or docs.
3. Identify affected routes/events, time window, property access, and responsible owner.
4. Notify the business owner and qualified privacy reviewer.
5. Remove the collection source, rotate access if needed, and request provider deletion/remediation.
6. Review property access and settings for related exposure.
7. Re-run route, consent/GPC, payload, inquiry, and Not Found negative matrices.
8. Record correction, deletion request/result, reviewer, and dates.
9. Reactivate only after privacy approval and clean production validation.
